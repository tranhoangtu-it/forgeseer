## ForgeSeer 1.1.0

Two things people asked for.

**Settings screen.** It opens first: pick the language (or let it follow the game), opacity,
font size, which panels to show, and whether to read the game live. Hit Start and it waits on the
taskbar while you play; click it there or press F6 to change something, it applies right away.
Tick "skip this screen next time" if you don't want to see it again.

**Your language.** The overlay now follows the language the game is set to: English, Korean,
Japanese, Simplified and Traditional Chinese, German, Spanish, Brazilian Portuguese, Russian and
Vietnamese. Outcome names, Frenzy, relic names and descriptions use the game's own wording where
the game has it. `--lang` still works if you want to force one.

Unzip, run ForgeTax windowed or borderless, start `ForgeSeer.exe`.
F6 settings, F7 legend, F8 hide, F9 move, F10 quit.
