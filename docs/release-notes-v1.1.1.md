## ForgeSeer 1.1.1

The overlay now fits on any screen.

On 1080p, 1440p, or with Windows scaling above 100%, the detail panel used to run off the bottom
of the screen. Now it shrinks the font first, then hides the less important lines (stats, relic
ranking, shop descriptions, plan details), then uses two columns if there's room. Only as a last
resort does it cut lines, and it tells you how many. It follows whichever monitor the panel is on,
so dragging it to another screen with F9 works too.

Nothing changes on a 4K screen at 100% scaling.

Unzip, run ForgeTax windowed or borderless, start `ForgeSeer.exe`.
